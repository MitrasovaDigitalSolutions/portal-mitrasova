# Shared Components

Reusable composed components used across multiple features.

Place components here only when they are needed by **2 or more** features.
Feature-specific components stay in `features/[name]/components/`.

## Examples of shared components:
- `DataTable` — generic paginated table
- `ConfirmDialog` — confirmation modal
- `PageHeader` — standard page header with breadcrumbs
- `EmptyState` — empty state illustration
